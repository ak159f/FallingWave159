# FallingWave159
An ultra-fast, low-latency audio spectrum analyzer written with Gemini. Built in C++, Raylib, and Miniaudio. Features live hot-swapping between high-res mastering (asymmetric windows) and high-speed breakcore transient analysis (zero-padding), all powered by WASAPI loopback capture.

### Controls
- **Space:** Swap mode
- **Arrow Up/Down:** Change waterfall speed
- **Toggle FullScreen mode:** F or F11
